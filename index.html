        How to use the generated skill.md
        
      

      

        
The generated file is a skill document. Give it to your AI coding assistant so it can build a complete, runnable project in the selected style and framework.

        
    
          
  1. Choose a UI style and framework, then save the generated .md file.
    2. 
          
  2. Put the file into your assistant skills folder, or attach it to the conversation.
    3. 
          
  3. Typical locations: ~/.claude/skills/<name>/SKILL.md, .trae/skills/<name>/SKILL.md, or any folder your agent scans.
    4. 
          
  4. Mention the skill in your prompt, for example "use the material-wpf-app skill to build a settings window".
    5. 
          
  5. The assistant follows the document and outputs the full project: every file, string boundaries, design tokens, and packaging commands.
    6. 
        

        
Note: the document body stays in English on purpose; this interface follows your language. Changing the style or framework also changes the exported file name.

      

      

        
      

    

  


  

    

      

        About
        
      

      

        
Liberate the UI framework ability of your APP!

        
All UI Styles Application Skill Generator turns a design language and a host framework into a ready-to-use skill document for AI coding assistants. Choose from 17 UI styles and 8 frameworks, preview the generated Markdown, then copy or save it. The document keeps the structure of the original skill and rewrites its design tokens, framework integration, string boundaries, and packaging steps, so an assistant can produce complete, runnable projects. Built with WPF and WebView2 in the Windows 11 Fluent style.
